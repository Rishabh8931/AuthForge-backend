# AuthForge

> A production-grade OAuth 2.1 and OpenID Connect Authorization Server built with Node.js and TypeScript.

## Overview

AuthForge is an open-source Identity Provider (IdP) designed to provide secure authentication and authorization for modern applications. The project follows OAuth 2.1 and OpenID Connect standards while focusing on scalability, maintainability, and production-ready architecture.

## Planned Features

- OAuth 2.1 Authorization Server
- OpenID Connect (OIDC)
- Authorization Code Flow with PKCE
- Client Credentials Flow
- JWT Access Tokens
- Refresh Token Rotation
- Token Introspection
- Token Revocation
- Dynamic Client Registration
- JWKS Endpoint
- User Authentication
- Session Management
- Role-Based Access Control (RBAC)
- Audit Logging
- Rate Limiting

## Tech Stack

- Node.js
- TypeScript
- Express.js
- PostgreSQL
- Drizzle ORM
- Zod
- JWT
